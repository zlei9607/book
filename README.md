# 图书借阅管理系统

Spring Boot + MyBatis-Plus + Thymeleaf + Layui 实现的图书借阅**管理端**系统。

- 图书 / 分类 / 读者管理
- 借阅管理：新增借出（可调借阅天数）、办理归还、按卡号/姓名/书名查询
- 首页数据看板

## 快速开始

1. 初始化数据库（会重建业务表并写入演示数据）：

```bash
mysql -uroot -p < init.sql
```

2. 确认 `src/main/resources/application.properties` 中的数据库账号密码

3. 确认本地封面文件存在：

```text
file/5793c405e8ef467c929519b39d9d92dc.png
```

4. 启动：

```bash
mvn spring-boot:run
```

## 访问入口

| 入口 | 地址 | 账号 |
|------|------|------|
| 管理后台 | http://localhost:8080/login | `admin` / `111111` |

## 业务规则

- 默认借期 **30 天**（新增借阅时可调整）
- 每名读者有可借上限（默认 5 册，可在读者管理中调整）
- 同一本书未还不可重复借
- 借出扣减可借库存，归还回补
- 超过应还日期自动标记为逾期
